# The example files in this folder

- `banco.png` is a 64x48 placeholder still. It travels with this example so
  the piece validates and dry-runs alone; replace it with the bench photo
  before a real send.
- `thread.toml` is the piece: a two-post thread whose first post carries
  the still with alt text and whose second replies text-only with the
  catalogue link as a card. Dry-run it with
  `facet run thread.toml --dry-run`; it sends nothing.
