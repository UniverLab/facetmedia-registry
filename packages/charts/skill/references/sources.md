# Sources

The rules in `SKILL.md` rest on these public sources. Where a licence allows
it, at most one short line is quoted; everything else is a paraphrased fact or
practice.

| Source | URL | Maintainer | Licence | Taken |
|---|---|---|---|---|
| matplotlib usage guide | https://matplotlib.org/stable/users/explain/quick_start.html | Matplotlib Development Team | PSF-2.0 (matplotlib licence) | Agg is the headless backend (`matplotlib.use("Agg")`); `figsize` is inches and `savefig` multiplies by `dpi` for PNG pixels; spines, grid and `bar_label` shape the editorial frame. Paraphrased. |
| Tufte chartjunk | https://en.wikipedia.org/wiki/Chartjunk | Edward Tufte (via Wikipedia summary) | CC BY-SA | Chartjunk is decoration that carries no data: drop shadows, 3D effects, heavy grids and redundant legends. Paraphrased. |
| Few data-visualization | https://www.perceptualedge.com/articles/visual_business_intelligence/rules_for_using_color.pdf | Stephen Few, Perceptual Edge | freely distributed PDF | One strong color for the data, muted neutrals for everything structural; gridlines hairline and behind the data. Paraphrased. |
