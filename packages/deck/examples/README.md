# The example files in this folder

- `slides.html` is authored for this example: three 1280x720 slides in one
  self-contained file, inline CSS only, no external assets, a sources footer
  on every slide.
- `modelos-de-lenguaje.html` was already in this folder: the approved
  one-page piece, kept unchanged and exported by `page.toml`.
- `slides.toml`, `presenter.toml` and `page.toml` are the pieces; nothing they
  name lives outside this folder.
