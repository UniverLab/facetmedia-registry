the flow

Copy, run, look.

  • facet example deck.slides copies the piece and every file it names.
  • facet run deck.slides slides.toml exports the PDF and one PNG per page.
  • facet preview serves the deliverable to a person.
Sources: the facet example design note; packaged examples in this registry.
what to look for

The example is the contract.

A self-contained example teaches the piece's shape better than any description: the inputs, the files that travel with it, and the verification it must pass.

If the example works, the capability works.
