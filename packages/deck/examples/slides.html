facetmedia · ejemplo

Una pieza,
una salida.

Cada capacidad del registro hace una cosa, recibe un archivo TOML y devuelve un entregable que se puede abrir y juzgar.

Fuentes: contrato de piezas de facetmedia; manifiestos del registro, 2026.
el flujo

Copiar, correr, mirar.

  • facet example deck.slides copia la pieza y cada archivo que nombra.
  • facet run deck.slides slides.toml exporta el PDF y un PNG por página.
  • facet preview sirve el entregable para una persona.
Fuentes: documento de diseño de facet example; ejemplos empaquetados en este registro.
qué buscar

El ejemplo es el contrato.

Un ejemplo que corre solo enseña la forma de la pieza mejor que cualquier descripción: las entradas, los archivos que viajan con ella y la verificación que debe pasar.

Si el ejemplo funciona, la capacidad funciona.
