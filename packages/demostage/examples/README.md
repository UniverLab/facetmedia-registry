# The example files in this folder

- `demo/score.toml` is the hand-written score, authored for this example: a
  typed `facet --help`, a wait for the `Usage` line and a clean exit. The
  demo CLI records it and exports `facet-example.gif` and
  `facet-example.svg`. It is a fixture of the piece, not a piece of its own,
  so its file stem deliberately does not repeat the capability's name.
- `demo.toml` is the piece that names the score.
