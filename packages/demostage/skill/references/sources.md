# Sources

The authoring habits in the skill come from one public page, read on
2026-11-14. It is the closest published guide of its kind: no public agent
skill for `demostage` exists, because the `demo` binary installs from an
internal distribution. Facet's score DSL is not that format, so every habit
below is a practice taken from it, rewritten here for `demo.toml`.
