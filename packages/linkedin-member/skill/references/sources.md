# linkedin-member sources

One row per source the skill and runner rely on, with the URL, maintainer
and licence as stated, and what was taken from it.

| Source | Maintainer | Licence | Taken |
| --- | --- | --- | --- |
| https://learn.microsoft.com/en-us/linkedin/marketing/community-management/shares/posts-api | LinkedIn Corporation | none stated (learn.microsoft.com, facts only, no wording taken) | The facts that the Posts API replaces legacy ugcPosts, that every call carries `Linkedin-Version: YYYYMM` plus `X-Restli-Protocol-Version: 2.0.0`, that `POST /rest/posts` carries author, commentary, visibility PUBLIC, a distribution with feedDistribution MAIN_FEED and lifecycleState PUBLISHED, that a 201 answers the Post ID in the `x-restli-id` header, and that single-image posts ride `content.media` with the image URN. |
| https://learn.microsoft.com/en-us/linkedin/marketing/community-management/shares/multiimage-post-api | LinkedIn Corporation | none stated (learn.microsoft.com, facts only, no wording taken) | The facts that a MultiImage post holds 2 to 20 images inline under `content.multiImage`, each with an `id` and optional `altText`, that images stay under 36,152,320 pixels in JPG, GIF or PNG (GIF up to 250 frames), and that the read-back answers each image with its `id` and the post with its `commentary`. |
| https://learn.microsoft.com/en-us/linkedin/marketing/community-management/shares/images-api | LinkedIn Corporation | none stated (learn.microsoft.com, facts only, no wording taken) | The facts that the Images API replaces the Assets API, that the upload starts with `POST /rest/images?action=initializeUpload` carrying `initializeUploadRequest.owner`, that the answer holds `value.uploadUrl` plus `value.image`, and that the bytes ride a PUT to the upload URL. |
| https://learn.microsoft.com/en-us/linkedin/consumer/integrations/self-serve/share-on-linkedin | LinkedIn Corporation | none stated (learn.microsoft.com, facts only, no wording taken) | The facts that the self-serve Share on LinkedIn product grants `w_member_social` for posting on behalf of an authenticated member (`urn:li:person:{id}`), and that OpenID Connect (`openid`, `profile`) provides `/v2/userinfo` with the `sub` member identifier. |
| https://learn.microsoft.com/en-us/linkedin/shared/authentication/authorization-code-flow | LinkedIn Corporation | none stated (learn.microsoft.com, facts only, no wording taken) | The facts that the sign-in is a three-legged authorization-code flow where the app directs the browser to LinkedIn's authorization page with client id, redirect URI, scope and state, that the code returns to the redirect URI, that access tokens last 60 days, and that refresh tokens are only issued to approved Marketing Developer Platform partners. |
