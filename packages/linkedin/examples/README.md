# The example files in this folder

- `banco.png` is a 64x48 placeholder still. It travels with this example so
  the piece validates and dry-runs alone; replace it with the bench photo
  before a real send.
- `post.toml` is the piece: one text post with the still and its alt text,
  published to the lab's organization account as PUBLIC. Dry-run it with
  `facet run post.toml --dry-run`; it sends nothing.
