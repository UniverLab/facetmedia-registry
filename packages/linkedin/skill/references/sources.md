# linkedin sources

One row per source the skill and runner rely on, with the URL, maintainer
and licence as stated, and what was taken from it.

| Source | Maintainer | Licence | Taken |
| --- | --- | --- | --- |
| https://learn.microsoft.com/en-us/linkedin/marketing/community-management/shares/posts-api | LinkedIn Corporation | none stated (learn.microsoft.com, facts only, no wording taken) | The facts that the Posts API replaces legacy ugcPosts, that every call carries `Linkedin-Version: YYYYMM` plus `X-Restli-Protocol-Version: 2.0.0`, that `POST /rest/posts` carries author, commentary, visibility PUBLIC, a distribution with feedDistribution MAIN_FEED and lifecycleState PUBLISHED, that a 201 answers the Post ID in the `x-restli-id` header, that single-image posts ride `content.media` with the image URN, and that the organization scopes need a Company Page role of ADMINISTRATOR, DIRECT_SPONSORED_CONTENT_POSTER or CONTENT_ADMIN. |
| https://learn.microsoft.com/en-us/linkedin/marketing/community-management/shares/multiimage-post-api | LinkedIn Corporation | none stated (learn.microsoft.com, facts only, no wording taken) | The facts that a MultiImage post holds 2 to 20 images inline under `content.multiImage`, each with an `id` and optional `altText`, that images stay under 36,152,320 pixels in JPG, GIF or PNG (GIF up to 250 frames), and that the read-back answers each image with its `id` and the post with its `commentary`. |
| https://learn.microsoft.com/en-us/linkedin/marketing/community-management/shares/images-api | LinkedIn Corporation | none stated (learn.microsoft.com, facts only, no wording taken) | The facts that the Images API replaces the Assets API, that the upload starts with `POST /rest/images?action=initializeUpload` carrying `initializeUploadRequest.owner`, that the answer holds `value.uploadUrl` plus `value.image`, and that the bytes ride a PUT to the upload URL. |
| https://learn.microsoft.com/en-us/linkedin/marketing/community-management/shares/post-api-schema | LinkedIn Corporation | none stated (learn.microsoft.com, facts only, no wording taken) | The facts that the author is a person or organization URN, that commentary is required, that content is optional (a post without it is text-only), that PUBLISHED is the only accepted state at creation, and that the member's organization access is found through the organization access control API. |
| https://learn.microsoft.com/en-us/linkedin/shared/authentication/authorization-code-flow | LinkedIn Corporation | none stated (learn.microsoft.com, facts only, no wording taken) | The facts that the sign-in is a three-legged authorization-code flow where the app directs the browser to LinkedIn's authorization page with client id, redirect URI, scope and state, that the code returns to the redirect URI, and that the app trades it for an access token plus refresh token. |
