# The example files in this folder

- `narration.wav` is synthetic, generated for this example with
  `kokoro.speak` (voice `ef_dora`, language `es`, 24 kHz mono). It is not a
  recording of a person.
- `dialogue.txt` is the exact text the clip says.
- `mouths.toml` is the piece: Rhubarb aligns the two and writes the mouth
  cues.
