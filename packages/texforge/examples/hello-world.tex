\section{The first integral}\label{sec:integral}

The identity opening this document is an immediate integral:

\begin{equation}
  \int_0^1 2x \, dx = 1.
  \label{eq:integral}
\end{equation}

The value of equation~\ref{eq:integral} reads in a single line, with no
bibliography and no auxiliary files.
