# The example files in this folder

- `clip.mp4` is a small placeholder clip copied from the repository test
  fixtures. It travels with this example so the piece validates and dry-runs
  alone; replace it with the real video before an upload.
- `inbox.toml` is the piece: one video with the caption the user pastes in
  the app, sent to the account's inbox as a draft. Dry-run it with
  `facet run inbox.toml --dry-run`; it sends nothing.
