# The example files in this folder

- `reference-voice.wav` is synthetic, generated for this example with
  `kokoro.speak` (voice `af_heart`, language `en-us`, 24 kHz mono, 10.7 s). It is
  a stand-in for the person's own 7-30 s reference recording, never a
  recording of a person.
- `speak.toml`, `clone.toml` and `profile.toml` are the pieces. `clone.toml`
  and `profile.toml` need material that only the person has: the comments at
  the top of each TOML say exactly what to replace.
