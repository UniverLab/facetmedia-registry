# The example files in this folder

- `banco.mp4` is a small placeholder clip copied from the repository test
  fixtures. It travels with this example so the piece validates and dry-runs
  alone; replace it with the real video before an upload.
- `upload.toml` is the piece: one video with its metadata, uploaded private by
  default. Dry-run it with `facet run upload.toml --dry-run`; it sends nothing.
